## Phase 03 Interaction Contracts

1. `painel/pedidos.html` must keep "Todos os pedidos" as default view and preserve the highlighted "Aguardando PIX" section.
2. Period filter is the only operational filter for manual review queue:
   - presets: Hoje, Ontem, 7 dias, 30 dias, Personalizado
   - invalid custom range must show inline error and keep previous valid selection.
3. Queue ordering contract: newest pending first (descending by creation datetime).
4. `painel/pedido_detalhe.html` when status is `aguardando_confirmacao` must show:
   - comprovante block
   - mandatory decision form with dropdown reason (`valido`, `invalido`, `outro`) + complementary text (>=10 chars)
   - separate visual emphasis for confirm vs reject actions.
5. Rejection action must require explicit confirmation interaction before submit.
6. Audit feed appears only in order detail page, newest first, with minimal fields:
   - action label
   - date/time
7. Success and error feedback must use existing Django flash alerts with clear next action.
